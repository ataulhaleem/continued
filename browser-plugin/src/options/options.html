E Enclave options

Enclave runs entirely in your browser. Prompts and page content go only to the model you select. Nothing else is collected.

Local models (Ollama)

Every model on that server appears in the sidebar dropdown. No key needed. Use a LAN address to share a GPU box with your team.

Cloud providers (optional)

Keys are stored in extension storage on this device, unencrypted. Prefer Ollama for anything sensitive.

Enclave needs the browser's site-access grant to reach a provider's API (and Ollama on another machine).

Agent

Off by default. When on, read-page and read-pdf can read an HTML, text or PDF file you opened from your disk, and its text goes to the selected model like any web page. Firefox does not let any extension read a PDF it displays from your disk (it blocks file:// fetches and shields its PDF viewer), so there a local PDF is attach-only: use the 📎 button in the chat, which works in both browsers without this setting. Chrome reads local PDFs once its file-access switch is on. The agent still cannot open file URLs on its own. The browser must also grant file access, which is a separate permission in Firefox 153+ and a switch on the extension's details page in Chrome.

Changes take effect as you make them: a field is saved when you leave it or press Enter, a checkbox the moment you tick it. Save stores everything on the page at once and asks the browser for site access if it is still missing.
