# Getting started

## 1. Pick a model provider

**On your machine (no data leaves it):** install [Ollama](https://ollama.com) and pull a model:

```bash
ollama pull llama3
```

**Institutional endpoint:** obtain a Blablador token as described in the
[Blablador API guide](https://sdlaml.pages.jsc.fz-juelich.de/ai/guides/blablador_api_access/).
Blablador speaks the OpenAI-compatible API at `https://api.blablador.fz-juelich.de/v1/`.

**Commercial providers** (OpenAI, Anthropic, Gemini) work with your own key. They are labelled as
remote in every model list, and nothing is sent to them until you select one.

## 2. Install a host

### VS Code

```bash
code --install-extension AtaUlHaleem.continued
```

or search the Marketplace. Open the sidebar, choose a model from the searchable picker, add keys
through the ⚙️ Settings button. Keys live in the editor's secret storage, not in settings files.

### Firefox and Chrome

Install from [addons.mozilla.org](https://addons.mozilla.org/firefox/addon/continued/) (Firefox 140
or newer, desktop). For Chrome, until the store listing is live, download the release zip, unpack it,
and load it from `chrome://extensions` with Developer mode on. Add keys on the options page.

### Terminal

```bash
npm install -g ./enclave-cli-<version>.tgz
export ENCLAVE_BLABLADOR_KEY=…        # optional
enclave models
enclave run
```

## 3. Run your first harness

In the editor or the browser, open the 🧩 view and run **Workspace health check** (editor) or
**Summarise this page** (browser). In the terminal:

```bash
enclave run workspace-health-harness --model llama3
```

Each step appears as it runs; a command asks for approval before it executes.

::callout{type="tip" title="Where things are stored"}
Harnesses, plugins and run records live in your workspace under `.continued/` (becoming `.enclave/`).
The browser extension keeps them in extension storage. Nothing is stored outside your machine.
::
